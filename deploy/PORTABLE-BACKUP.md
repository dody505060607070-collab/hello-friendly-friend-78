# حفظ ونقل نظام الرشودي بأمان

## ما يُحفظ في GitHub

يحفظ GitHub كود الموقع، ملفات النشر، مخطط قاعدة البيانات، وسياسات الصلاحيات،
وإعدادات الأتمتة البرمجية. عند ربط المشروع بـGitHub تتم مزامنة هذه الملفات تلقائيًا.

لا تُحفظ كلمات المرور أو مفاتيح الذكاء الاصطناعي وواتساب أو جلسة QR أو أرقام العملاء
كنص مكشوف داخل المستودع، حتى لو كان خاصًا. تسريب مفتاح واحد قد يسمح بإرسال رسائل أو
قراءة بيانات أو التحكم في الموقع.

## ما يلزم لنسخة مطابقة

النسخة الكاملة تتكون من جزأين:

1. **مستودع GitHub:** الكود وملفات التشغيل والقوالب.
2. **نسخة مشفرة:** قاعدة البيانات والحسابات والأتمتة والملفات والإعدادات السرية وجلسة واتساب.

بهذا يمكن نقل الموقع كما هو دون نشر الأسرار.

## إنشاء النسخة المشفرة على الخادم

```bash
cd /var/www/mithraa
export PORTABLE_BACKUP_PASSWORD='كلمة تشفير طويلة لا تحفظها في GitHub'
bash deploy/scripts/08-export-portable.sh
```

ينتج ملف خارج مجلد المشروع داخل `/var/backups/rashoudi-portable/` باسم قريب من:

```text
rashoudi-full-20260913T190000Z.tar.gz.enc
```

يشمل الملف المشفر:

- قاعدة البيانات والحسابات وبيانات النظام وإعدادات الأتمتة.
- ملف إعدادات الخادم السري.
- الصور والعقود والملفات المرفوعة إن كانت على قرص الخادم.
- جلسة واتساب المرتبطة بالـQR إن كان الجسر المحلي مستخدمًا.

احفظ كلمة التشفير في مدير كلمات مرور منفصل. يمكن رفع الملف **المشفر فقط** إلى تخزين
خاص أو إصدار خاص في GitHub، لكن لا ترفع النسخة المفتوحة ولا كلمة التشفير.

## أسرار النشر عبر GitHub

عند استخدام GitHub Actions، أضف القيم السرية في إعدادات Secrets الخاصة بالمستودع،
ولا تضعها في أي ملف ملتزم. القالب الكامل للأسماء المطلوبة موجود في `deploy/.env.example`.

## قبل الانتقال

1. تأكد أن كود GitHub محدث.
2. أنشئ نسخة مشفرة حديثة.
3. احتفظ بكلمة التشفير خارج GitHub.
4. اختبر فك النسخة على خادم تجريبي.
5. بعد النقل غيّر مفاتيح الربط الحساسة إذا شاركها أي شخص سابقًا.

> ملاحظة: اتصال الشات المشترك بمثراء يعتمد على تسجيل دخول الموظفين وسياسات مثراء؛
> لا تُنسخ بيانات مثراء ولا مفاتيحه الخاصة ضمن نسخة الرشودي.
