# جسر واتساب المجاني (يعمل على الـVPS)

يربط رقم واتساب حقيقي (رقمك الشخصي أو رقم الشركة) عبر مسح رمز QR مرة واحدة،
وبعدها يرسل النظام الرسائل من نفس الرقم مباشرة ومجانًا — بدون Twilio وبدون قوالب.

## التثبيت على Hostinger VPS

```bash
cd /var/www/mithraa/deploy/whatsapp-bridge
npm install
npm i @hapi/boom
export BRIDGE_TOKEN="ضع-توكن-عشوائي-طويل"
pm2 start server.js --name whatsapp-bridge --update-env
pm2 save
```

اجعل الخدمة خلف Nginx بـ HTTPS، مثلًا:
`https://wa.mithra.work` → `http://127.0.0.1:3010`

## متغيرات البيئة المطلوبة في التطبيق

| المتغير | القيمة |
| --- | --- |
| `WHATSAPP_BRIDGE_URL` | `https://wa.mithra.work` |
| `WHATSAPP_BRIDGE_TOKEN` | نفس `BRIDGE_TOKEN` |

بعد ضبطها، افتح في لوحة التحكم صفحة **ربط واتساب**، امسح رمز QR من تطبيق واتساب
(الأجهزة المرتبطة ← ربط جهاز)، وبعدها كل زر «إرسال تذكير» يرسل من رقمك فورًا.

## الأمان والحدود

- الجلسة محفوظة في مجلد `auth/` — لا تحذفه وإلا يلزم مسح QR من جديد.
- هذا استخدام غير رسمي لواتساب؛ الإرسال المكثّف أو البلاغات قد يؤدي لحظر الرقم.
- إن فشل الجسر لأي سبب، يعود النظام تلقائيًا لاستخدام Twilio.
