# خطوات الرشودي على نفس سيرفر مثراء (بدون أي تأثير على مثراء)

قاعدة ذهبية: كل اسم ملف/مجلد/مهمة/قناة واتساب هنا جديد ومختلف عن مثراء.
ممنوع فتح أو تعديل: `/root/mithra-jobs/`، instance واتساب باسم `mithra`، وworkflows مثراء في n8n.

## 0) ما تحتاجه قبل البدء

- IP السيرفر + كلمة مرور المستخدم root (من لوحة Hostinger: VPS ← Overview).
- دومين موقع الرشودي الجديد (مثال: `rashoudi.com`).
- التوكن السري للموقع الجديد: `290a526c...` (موجود بالفعل داخل إعدادات الموقع، ولا يُنشر لأحد).

## 1) الدخول على السيرفر

1. من لوحة Hostinger افتح: VPS ← اسم السيرفر ← زر **Browser terminal**.
2. سجّل الدخول باسم `root` وكلمة المرور.
3. تأكد أن مثراء شغال قبل أي شيء:
   ```
   curl -s -o /dev/null -w "%{http_code}\n" https://evo.tradex1.cloud
   ```
   لازم يرجّع رقم (200 أو 404 مقبولان) — المهم السيرفر يرد.

التأثير: لا شيء. مجرد قراءة.

## 2) إنشاء قناة واتساب جديدة للرشودي

القناة الحالية للموقع الجديد اسمها مختلفة عن `mithra` (اسمها داخل إعدادات الموقع: `WHATSAPP_INSTANCE`).
لا تنفّذ أي أمر حذف/logout على `mithra` نهائيًا.

الربط يتم من داخل الموقع الجديد مباشرة:
1. افتح موقع الرشودي ← **إعدادات الموقع ← ربط واتساب**.
2. اضغط "إنشاء/تحديث الربط" ثم امسح رمز QR **برقم الرشودي فقط**.
3. تظهر الحالة "متصل".

التأثير: يُنشئ قناة جديدة داخل Evolution API. قناة مثراء تبقى كما هي.

## 3) مهمة كل ساعة (cron) خاصة بالرشودي

مجلد جديد تمامًا: `/root/rashoudi-jobs/` (ليس مجلد مثراء).

1. أنشئ المجلد والملف:
   ```
   mkdir -p /root/rashoudi-jobs
   nano /root/rashoudi-jobs/reminders.sh
   ```
2. الصق هذا المحتوى بعد استبدال الدومين والتوكن:
   ```bash
   #!/bin/bash
   curl -s -X GET "https://rashoudi.com/api/public/n8n" \
     -H "x-mithra-token: ضع_التوكن_هنا" \
     >> /var/log/rashoudi-reminders.log 2>&1
   echo " <- $(date)" >> /var/log/rashoudi-reminders.log
   ```
3. احفظ (Ctrl+O ثم Enter) واخرج (Ctrl+X)، ثم:
   ```
   chmod +x /root/rashoudi-jobs/reminders.sh
   /root/rashoudi-jobs/reminders.sh && tail -n 3 /var/log/rashoudi-reminders.log
   ```
   المتوقع سطر فيه `"ok":true`.
4. جدولة كل ساعة دون المساس بمهام مثراء:
   ```
   crontab -l > /tmp/cron.bak
   (crontab -l; echo "5 * * * * /root/rashoudi-jobs/reminders.sh") | crontab -
   crontab -l
   ```
   لاحظ الدقيقة 5 حتى لا تتزامن مع مهمة مثراء. ولو أردت التراجع: `crontab /tmp/cron.bak`.

التأثير: يضيف سطرًا واحدًا جديدًا لجدول المهام. لا يُعدّل أي سطر قائم.

## 4) ماذا يفعل هذا الرابط كل ساعة

`GET /api/public/n8n` بالتوكن يقوم بـ:
- إرسال كل التذكيرات/المتابعات المستحقة عبر واتساب، وتسجيلها في سجل الرسائل.
- إعادة جدولة التذكيرات المتكررة (يومي/أسبوعي/شهري…) وإغلاق التذكير المرة الواحدة.
- تنبيه الفريق مرة يوميًا بالدفعات المتأخرة.

## 5) اختبار نهائي

```
curl -s -H "x-mithra-token: التوكن" https://rashoudi.com/api/public/n8n
curl -s -o /dev/null -w "mithra: %{http_code}\n" https://<دومين-مثراء>/
```
الأول يرجّع `{"ok":true,...}`، والثاني يرجّع 200 → مثراء سليم.

## 6) n8n (اختياري)

لو أردت workflows إضافية: أنشئ workflow جديد باسم `Rashoudi - ...` فقط، ولا تفتح أو تعدّل أي workflow باسم مثراء.
